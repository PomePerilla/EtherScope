# 验收方法

## 先确认范围

记录项目、版本／提交、入口、数据场景、主题、语言、尺寸与缩放。缩放、浏览器缩放、设备比例、Qt 逻辑像素和物理 DPI 分别记录。

已有验收门槛继续使用。没有性能基线时，先记录同一数据集的改动前结果，再按主任务约定门槛。包自带检查只验证配置和模板；目标项目需另测实际交互与任务。

## 选择验证矩阵

- 默认参考尺寸：900×580、1024×768、1440×900；移动或触屏项目使用自身尺寸。
- 当前支持的每种语言与深浅主题；长来源、长地址、长翻译、多条件及横向滚动。
- 100%、150%、200% 可用作默认缩放参考。原生跨显示器、混合 DPI、窗口最大化与位置恢复单独执行。
- 空闲、准备、运行、等待、筛选为空、错误、导出／保存、关闭／停止；状态用真实服务或受控钩子驱动。

## 关键可观察结果

| 路径 | 核对 |
|---|---|
| 选中 → 字段 → 原始内容 | 对象正确、范围正确、暖黄色联动，更新后阅读位置稳定 |
| 筛选 → 移除 → 撤回 | 输入草稿和已应用条件一致、错误输入不破坏已有结果 |
| 查找 → 定位 → 返回 | 查询范围正确、目标稳定、跨页正确、来源过期不跳到同号对象 |
| 停靠 → 浮动 → 关闭 | 不重复任务、状态保留、关闭安全、最小窗口未被抬高 |
| 键盘 → 菜单 | Ctrl+C 按焦点、Ctrl+F 按范围、Esc 层级清楚、无重复快捷键 |
| 设置 → 重启 | 主题、语言、布局可恢复，屏幕外窗口修正 |
| 连续更新 | 事件响应、合并更新、内存预算和停止耗时保持项目门槛 |

界面用例涉及剪贴板时顺序运行。保存改前／改后截图，记录模拟数据和真实数据的区别。人工视觉检查覆盖主工作区、辅助窗口、状态与文本。

## 交付记录模板

```text
版本／提交：
入口与独立设置：
修改：
自动检查（命令、环境、结果）：
界面矩阵（实际执行组合）：
状态／交互／性能结果：
截图与日志路径：
未执行项与原因：
```

不把截图数量当成功能验收，也不把合成负载当真实硬件验收。记录状态直述事实和下一步。
