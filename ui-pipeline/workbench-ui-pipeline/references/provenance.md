# 来源与范围

管线版本：1.0.0。

抽取基线：EtherScope v2.3.0，本地提交 `74dff379fe3d4c0b528fe23fe4c98af980be5b2d`。抽取时间：2026-10-28。

| 原项目依据 | 抽取内容 |
|---|---|
| `src/ui/style.h`、`main_window_theme.cpp` | 深浅主题语义色、13px 正文、30px 控件、26px 数据行、尺寸与控件状态 |
| `main_window_ui.cpp`、`flow_layout.h` | 来源与动作层、条件层、内容层、状态层及按实际尺寸换行 |
| `analysis_dock.*`、`main_window_workspace.cpp` | 来源条、紧凑标题、停靠／浮动、空间不足和布局恢复原则 |
| `application_view.*`、`source_context.h` | 稳定身份、绑定代数、分片刷新、阅读位置、失效行为 |
| `find_bar.*`、`reading_history.h` | 查找、筛选和阅读历史分离，键盘和过期目标处理 |
| `docs/视觉设计规范.md`、`交互工作区.md`、`检索与课程验收.md` | 整套视觉一致性与可记录的验证方式 |

这份包独立携带参数、说明、生成器和通用样板，不依赖原仓库路径。仅 `FlowLayout` 从原 MIT 源码改为通用命名空间；其余适配是面向新项目的独立模板。

原项目的品牌、Ethernet／协议字段、解析任务、Npcap、窗口原生事件处理、业务限额和已有测试结果留在原项目。新项目执行自身的接入与验收，选择需要的窗格和状态。

维护时以包内 token 为准，用配置覆盖进行派生；改动生成器时执行自测，再检查实际样板。安装副本通过内容校验与包版本识别，避免手改多个主题文件导致漂移。
