# 布局与交互

## 六层工作区

| 层 | 内容 | 收缩规则 |
|---|---|---|
| 窗口／品牌 | 品牌、标题、窗口操作 | 原生或已验证的自绘标题栏 |
| 全局动作 | 来源、主操作、打开／保存、分析、更多 | 来源弹性省略，保留完整提示；关键操作可见 |
| 视图与条件 | 来源页签、快捷条件、表达式、跟随 | 控件按真实宽度换行 |
| 生效条件 | 可逐项移除的条件条 | 长值省略、完整提示、条件可换行 |
| 内容 | 列表、检查器、编辑器或图表 | 与主任务匹配；数据表可横向滚动 |
| 状态 | 当前状态、常用计数、诊断入口 | 详细资源信息按需展开 |

检索条靠近被检索工作区，Ctrl+F 依焦点确定范围。导航后退／前进靠近详情操作，避免与筛选撤回混淆。

## 可选布局

`list-inspector`：主列表＋字段／详情。存在有用的原始内容时，再增加文本／字节区。宽窗口并排，窄窗口上下排列或转为详情页签。

`navigation-content`：左侧导航＋内容；第三栏仅在确有检查需求时显示。适合配置、内容管理和多模块业务。

`monitor-analysis`：主监控面保留，分析与诊断按需打开。桌面可用停靠／浮动；Web 可用侧栏、抽屉或对话框。独立窗口需要单独的键盘和关闭验证。

分析区必须在标题栏与全局工具条之下。面板名称在标题或页签中表达一次；来源与对象编号分别布局，长来源省略。初始停靠由可用尺寸和内容最小尺寸决定，避免面板抬高主窗口最小尺寸。记录用户布局偏好，临时空间不足与用户主动浮动分开处理。

## 状态和数据契约

```text
ViewBinding = source_id + data_generation + analysis_generation? + entity_id
MessageKey  = stable business identity + stream/offset when relevant
FieldKey    = stable field id + location + duplicate occurrence
```

按目标业务精简字段。刷新不要用行号、翻译后的字段名或释放后的指针作身份。更新同一绑定时保留选择、滚动锚点、页码、未变化文本的选区和说明展开状态；绑定改变后清空旧阅读状态。目标消失时清空相应详情并提示，避免自动跳到邻近条目。

| 交互 | 保存内容 | 有效期／执行规则 |
|---|---|---|
| 右键菜单 | 来源、对象、字段与打开时值 | 复制冻结值；变更前校验目标和来源 |
| 显示筛选 | 完整已应用条件 | 与输入草稿、后台采集过滤分开 |
| 查找 | 查询、范围、结果稳定键与位置 | 提示刷新，执行前验证目标，保持筛选 |
| 阅读历史 | 对象、字段、页码、锚点 | 限量、本次绑定内，过期提示或跳过 |
| 持续更新 | 当前快照与最新待处理快照 | 合并过期更新，分片／后台处理保持响应 |

数值预算、历史条数、分片时长由业务和基准决定。EtherScope 的 20 条筛选、50 步历史、4 KiB 分页和约 2 ms 分片是来源项目参数，不作为跨项目硬性门槛。

## 关闭和键盘

同一动作在菜单、按钮和快捷键中共享条件。Esc 先处理当前查找／弹层，再处理外层面板；Ctrl+C 尊重当前焦点及文本输入。移动、停靠、语言切换不重建正在工作的任务。关闭时取消并等待自身任务，通过原有安全退出路径收尾。
