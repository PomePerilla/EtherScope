# 视觉系统

`assets/tokens.json` 是参数的唯一源。修改 `project-contract.json` 的 `token_overrides`，按相同层级覆盖，再运行生成器。示例：

```json
{"token_overrides":{"metrics":{"row_height":30},"colors":{"dark":{"accent":"#D8B43C"}}}}
```

## 角色与规则

| 层级 | 默认 | 应用 |
|---|---|---|
| 工作区／数据区／工具条 | 深灰或浅灰三层底色 | 用层级与细边界组织内容 |
| 主操作 | 黄色填色＋深色文字 | 当前任务最主要的一项操作 |
| 强调 | 深色黄、浅色棕黄 | 焦点、当前页签、可操作标记 |
| 选中 | 暖黄低亮度底色 | 列表、字段及对应内容联动 |
| 错误／正常／警告 | 红／低饱和青绿／暖黄 | 同时给图形或标记和文字 |
| 主文字／辅助文字 | 两级可读对比度 | 标题、来源、状态与数值各司其职 |

正文默认 13px；地址、时间、序号、长度和原始数据使用等宽字体。控件 30px、数据行 26px、标题 28px；间距 4/8/12/16px，圆角 4px。密度由项目可读性决定，触屏项目应另设更大的命中范围。

表格采用低对比交替行，避免用高饱和协议／类型标签占满每一行。边框用于界定容器，阴影用于浮层。动画用于展开、焦点或状态过渡；尊重系统减少动态设置。

检查整套控件：表格、字段树、字节／文本、按钮、输入框、下拉、页签、菜单、提示、对话框、空状态、诊断与设置。新增界面只通过语义 token 引入颜色。

## 图标与品牌

功能图标以 20px 网格、约 1.8px 圆端笔画为默认。主要动作使用图标＋文字；辅助图标按钮有名称与提示。沿用项目图标库，避免额外引入整套依赖。

每个窗口壳只安排一个品牌入口；系统窗口／任务栏图标按操作系统规则保留。E＋信号弧品牌属于 EtherScope，本管线用通用图形占位，不自动转移品牌。

## 文案

- 字段：“用途＋当前值含义”，一至两句，保留单位和原始值。
- 状态：“当前状态＋操作”，如“数据尚未完整，可继续采集”。
- 错误：给具体对象、失败原因和可执行入口。
- 无数据时区分尚未开始、等待、筛选为空和来源不可用。

产品文案聚焦当前操作，删除额外的推断性结语。证据范围和未执行验收写在验证记录中。
