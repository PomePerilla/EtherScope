# EtherScope 视觉设计规范

本轮设计面向持续抓包与网络排查，延续黄黑工具感，保留数据包、字段、原始字节三窗格。界面以紧凑阅读和明确反馈为优先，默认深色，浅色与三种语言使用同一套规则。

黄色标识开始操作、当前页签、焦点和有效开关。警告另用三角轮廓与可读文字；错误用红色圆叉与具体错误说明。协议名称保持中性文字。数据包状态还可通过状态列、提示和无障碍文本读取。字段选择对应的字节使用相同选中色，避免另外引入蓝色。

按相对亮度计算，主要文字对数据区的对比度为深色 14.61:1、浅色约 14.8:1；次级文字为 7.81:1 和 5.89:1；主操作文字对黄色为 8.91:1。图标与文字共同表达含义。

## 字体、尺寸与控件

- 界面：Segoe UI，中文回退 Microsoft YaHei UI，13 个逻辑像素。
- 地址、时间、长度和原始字节：Consolas，回退 Cascadia Mono / Courier New，13 个逻辑像素。文本摘要与协议名称使用界面字体。
- 控件外高 30px，表格行高 26px，面板标题高 28px；4/8/12/16px 间距，控件圆角 4px。
- 表格采用轻微交替行色；边界和网格保持低对比。选中态、悬停、按下和键盘焦点分别定义；禁用的主按钮取消黄色实心填色。
- 分隔条提供 5px 拖动区域，以一条细线显示边界；悬停时显示温和的选中色。
- TCP、流数据、应用分析、捕获过滤及录制设置共用全局字体、控件和主题参数。

运行时规范集中于 `src/ui/style.h`，主题应用位于 `src/ui/main_window_theme.cpp`。

## 品牌与图标资源

品牌以用户提供的参考图为依据，保留 E 与两道信号弧线，使用圆端、统一间隔和清晰负空间。16–24px 版本扩大内部负空间并调整弧线粗细。

| 资源 | 用途 |
| --- | --- |
| `src/ui/icons/brand-on-light.svg` / `.png` | 浅背景深色透明标志 |
| `src/ui/icons/brand-on-dark.svg` / `.png` | 深背景黄色透明标志 |
| `src/ui/icons/brand-on-navy.svg` / `.png` | 保留参考图海军蓝的透明版本 |
| `src/ui/icons/app-{size}.png` | 黄色圆角底、深色标志的应用图标 |
| `src/ui/icons/etherscope.ico` | 16/20/24/32/48/64/128/256px 八帧系统图标 |
| `src/ui/icons/brand-sizes.png` | 应用图标尺寸检查图 |
| `src/ui/icons/functional-icons.png` | 功能图标目录 |

功能图标在 `src/ui/icons.cpp` 中以 QPainter 路径绘制：20px 基准网格、1.8px 圆端笔画，按主题、逻辑尺寸、设备比例及 Normal/Disabled/Active/Selected 状态生成缓存。品牌母版与应用资源通过 `visual_assets` 构建目标和 `scripts/render_visual_assets.cpp` 再生，不增加 Qt SVG 模块或网络依赖。

```powershell
.\scripts\build.ps1 -Targets visual_assets
$env:PATH = (Join-Path $PWD '.tools\Qt\bin') + ';' + $env:PATH
.\build\msvc-release\visual_assets.exe src/ui/icons -platform offscreen
```

主要功能使用图标加文字：开始、停止、打开、保存、分析与更多。刷新、展开和移除采用紧凑图标，并提供可访问名称或完整提示。品牌 ICO 同时接入 Qt 窗口、程序 PE 资源与安装器资源。

## 操作组织

- 品牌只在主窗口标题区显示一次；主工具栏为网卡与刷新、开始/停止、打开/保存、分析、更多。分析菜单承载 TCP 会话与当前数据包应用分析；未选数据包时禁用应用分析，并在提示中说明原因。
- 更多菜单分为捕获设置、TLS 密钥日志、外观与语言。刷新与显示表达式等入口复用相同 QAction，启用和选中状态只有一个来源。
- 筛选操作条保留实时/文件、协议、ICMP 类型、地址、表达式、跟随和统计。生效条件放入独立可换行条件行，逐项移除；长地址省略显示，提示保留完整文本。
- 工具按钮、筛选条与条件行根据实际翻译后的尺寸换行；表格仍使用横向滚动。地址输入保留原有宽窄窗口两行适配。
- 跟随暂停时显示“已暂停跟随”，勾选恢复；滚动与历史选择继续沿用原有跟随行为。
- 空状态分别提示尚未开始、准备中、等待数据、停止中、没有匹配包或没有网卡，提供对应操作。字段与字节区域在没有选择时显示选择提示。
- 原有 Ctrl+O、Ctrl+S、Ctrl+Enter、F5 和 Esc 行为继续使用；抓包、后台保存、录制与设置格式保持兼容。

## 主窗口与标题栏

主窗口采用无边框、自绘标题区，保留窗口和任务栏的系统应用图标。界面内仅标题区有一个 20px 品牌标识，原工具栏标识移除。

- 标题区高 32px，应用名称 13px；右侧最小化、最大化/还原、关闭按钮各宽 44px。控件平面化，关闭按钮悬停变红，最大化后切换还原图形和提示。
- 窗口按钮不抢占数据区的键盘焦点；提供三语言提示与无障碍名称。
- 标题区空白与应用名称可拖动，双击最大化/还原；窗口按钮与工具栏控件不属于拖动区域。
- Windows 保留原生边缘缩放、系统窗口样式及大小图标。最大化使用当前显示器工作区，内容不延伸到任务栏；支持的系统版本使用 DWM 圆角和阴影，不通过透明遮罩裁切内容。
- 关闭按钮进入既有安全关闭流程：捕获、录制或后台保存未结束时等待，保存失败仍保留窗口。
- 本轮只调整主窗口的外框；TCP、应用分析和设置对话框继续采用各自已有的窗口结构。

实现为 `WindowTitleBar` 和主窗口原生事件处理；拖动使用系统窗口移动接口，Windows 边缘命中与客户区计算遵循 [Qt 窗口文档](https://doc.qt.io/qt-6.8/qwindow.html#startSystemMove) 和 [WM_NCCALCSIZE 文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-nccalcsize)。

## 验证入口

新增 `visualSystemLayoutsAndResources` 与 `visualCaptureAndEmptyStates`，检查图标八帧资源、主题联动、动作共享、选择前后启用状态、布局无重叠与实际状态切换。与既有界面交互测试一起执行。

视觉矩阵为 900×580、1024×768、1440×900，三种语言、深浅主题、100%/150%/200% 缩放，并覆盖有包三窗格和长 IPv6 多条件场景。关键状态采用受控捕获与写入钩子，驱动实际状态机和录制/导出服务。

截图、测试报告与改动前后 60 秒、1000 包/秒合成基准存于 `output/evidence/visual-system/`。这些结果验证视觉和界面回归，不扩展已有真实网络功能的验收结论。本轮不发布版本。

上述规范形成于本地预览阶段。随后用户授权将该视觉与窗口方案作为 v2.1.0 正式发行；发布版部署方式见 `docs/部署说明.md`。
