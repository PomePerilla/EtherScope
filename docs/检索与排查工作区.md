# EtherScope v2.3.0 检索与排查工作区

本轮为本地预览。沿用黄黑视觉、无边框主窗口、三窗格和可停靠分析。

## 查找

主窗口详情标题区和应用分析工具条均有“查找”。Ctrl+F 根据当前焦点打开对应查找条，Esc 收起。

| 范围 | 内容 |
|---|---|
| 报文列表 | 当前显示条件下、当前可见列的文字 |
| 当前字段 | 字段名称和值，包括折叠字段 |
| 当前报文字节 | 所选报文全部已捕获字节，支持跨 4 KiB 页定位 |
| 应用消息 | 当前结果中的协议、消息摘要和字段 |
| 当前消息字节 | 所选消息当前数据来源的完整字节缓冲 |

输入文字或完整十六进制字节，按 Enter 或“重新查找”开始；随后使用“上一个／下一个”定位。输入最多 4,096 个字符。查找保持现有显示条件。查找使用打开时的快照，更新后可重新查找；最多显示 10,000 项。文本搜索支持大小写选择；原始字节文本按 UTF-8 编码，大小写折叠覆盖 ASCII 字母。

查找在界面线程按约 2 ms 分片，支持取消。报文快照只复制显示元数据，消息字节共享不可变缓冲。结果保存稳定身份和偏移；定位前重新验证来源与目标。

## 返回阅读位置

主窗口和应用分析各有“后退／前进”，支持 Alt+Left／Alt+Right。搜索定位和分析定位会记录跳转前的位置，普通方向键移动保持原有行为。

每个工作区最多记录 50 步，仅本次运行有效。主窗口的实时、文件来源分别保存历史；来源重置后清空。应用分析绑定改变后清空历史。恢复内容包括报文或消息、字段、字节页和滚动位置；应用分析同时恢复包号与说明展开状态。

报文被筛选隐藏时提供调整筛选提示；被覆盖或消息已淘汰时可跳过历史项。停靠、浮动和语言切换继续使用同一分析组件。

## 诊断

状态栏“诊断”打开可停靠、可浮动的面板。面板按捕获情况、分析进度和资源占用分组，长内容可滚动。较窄工作区首次展开时浮动。

驱动计数未知时显示“未知”。分析输入队列、解析状态与待交付结果分别显示占用。捕获计数是当前来源的累计值，分析状态按当前缓存报文统计。

## 大消息路径

不可变分析更新的内存估算在后台构造时计算并缓存，避免在界面取结果所用互斥锁中重复遍历大型字段索引。保留既有输入、状态、交付和索引预算。

消息窗口与字段索引合并超出交付预算时，按整条消息移除最旧输出，优先交付最近完整消息，并显示资源受限状态。已解析字段保留，消息字节和偏移保持原样；仅剩一条消息仍无法容纳时沿用受限通知。

基准新增单次结果峰值、字段索引峰值、受限更新次数及当前待交付受限报文数。累计受限记录计数可能包含同一报文的多次更新，当前待交付数量按报文 ID 去重。

验证记录见本轮 `output/evidence/2.3.0/`。课程功能核对见[课程要求核对](课程要求核对.md)。
