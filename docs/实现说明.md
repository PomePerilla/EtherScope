# EtherScope 1.8.0 实现说明

## 数据流

Npcap 或经典 PCAP -> RawPacket -> decodeSummary -> 有界队列 -> SessionStore -> 筛选与界面。

解析结果与原始字节放在不可变共享报文中。界面每 100 毫秒批量更新。导出共享点击保存时的报文快照。

| 模块 | 职责 |
|---|---|
| core | 协议解析、过滤、PCAP、会话缓存 |
| capture | Npcap、后台准备、队列、异步停止、导出 |
| ui | 数据包列表、字段树、原始字节、统计、设置 |

## 解析

Ethernet、单层 802.1Q、IPv4、ICMP、ARP、TCP、UDP、IPv6、扩展首部与 ICMPv6 使用统一字节边界检查。字段携带偏移与长度，关联原始字节定位。

IPv4 TCP 首片携带不完整 TCP 首部时显示“不完整首部”。捕获截断或非法数据偏移仍报告解析错误。非首片保留网络层字段，不进行重组。

IPv4 选项支持 EOL、NOP、记录路由和格式 0、1、3 的时间戳。其他选项保留类型、长度和原始范围。所有选项限制在 IHL 内，校验长度与指针；EOL 后显示填充。

`Packet::ipv4Checksum`、`icmpChecksum` 保存状态与可选计算值。IPv4 首部完整即可校验；ICMPv4 仅在完整且未分片时校验。校验范围按 IPv4 声明长度计算，排除 Ethernet 填充。校验不一致单独展示，不计入解析错误、警告或异常数。

完整解析接口 `decodePacket()` 保留。摘要路径省去字段对象与显示字符串，完成相同的长度、选项、异常、字段上限及校验和检查。

选择报文后，详情线程通过 `decodeDetails()` 读取共享原始字节。服务保留一个活动任务、一个待处理请求和一个完成结果；新选择覆盖旧请求。请求代号及报文对象拦截过期结果，字段控件按每批 2 毫秒填充。仅保留当前详情。

## TCP 分析

TCP 会话以双向 IP、端口和 VLAN 标识聚合，实时与文件分别维护。新 SYN 序号和关闭后的 SYN 创建新会话。记录双向包数、线上字节、载荷字节、SYN 应答时间、完整握手时间及 SYN/FIN/RST 事件。

握手完成要求依次观察 SYN、反向 SYN ACK 和正向 ACK，并匹配序号与确认号。序号计算按 32 位回绕，包含 SYN 载荷。双向 FIN 均获确认后显示“FIN 已确认”。RST 显示“RST 已见”。时间戳倒退时不显示相应耗时。

协议依据：[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)。分组对照：[Wireshark TCP Analysis](https://www.wireshark.org/docs/wsug_html_chunked/ChAdvTCPAnalysis.html)。

TCP 分析不保存原始报文引用，最多保留 1,024 个会话，每个会话保留最近 16 条事件，达到上限按最近使用顺序淘汰。占用与覆盖单独显示。完整性不足的 TCP 报文跳过会话推断。会话筛选与显示条件取交集；跨会话、重新打开文件和新捕获时清除会话条件，设置不保存临时会话编号。

入口为“更多 > TCP 会话”。“查看报文”应用会话条件，“定位”选择对应缓存报文。PCAP 重开后按文件记录重新分析。

“流数据”取得当前缓存中该连接的不可变快照，包含被显示条件隐藏的报文。后台按两个方向重组，使用 SYN 后数据序号及 32 位回绕计算。重叠范围保留最早观察到的字节，分别记录重复数据、部分重叠、顺序缺口、后到补齐与冲突。冲突关联首个字节不一致的原始包，双击包号可以定位。

缺失范围保留 SEQ 和长度，不填充字节或拼接跨缺口内容。未观察到 SYN 时显示“起点未知”；缓存淘汰显示“缓存范围”。FIN 可确定缺失尾部。数据越过 SYN/FIN 边界时显示“序号边界”。重复数据和先后顺序是捕获观察，不直接等同于网络重传或丢包。

重组使用一个活动任务和一个可覆盖的待处理请求，切换会话时取消旧任务。结果同时校验请求代号、会话编号和会话代数。任务结束立即释放原始报文引用，界面仅保留当前结果。表格按模型读取，十六进制与 ASCII 每页最多 1 KiB。

| 重组限制 | 数值 |
|---|---|
| 快照报文 | 10,000 |
| 单次快照原始字节 | 16 MiB |
| 每方向唯一字节 | 1 MiB |
| 每方向数据片段 | 4,096 |
| 每方向序号跨度 | 64 MiB |
| 分析标记 | 1,024 |

达到限制后保留已有结果并显示“达到上限”，超出标记单独计数。活动与待处理快照各自受限，共享报文与缓存重叠部分不重复计为独立原始数据。重组结果占用单独估算。IP 分片重组、TCP 超时诊断和 TLS 解密未实现。

## 过滤

BPF 通过 `LiveCaptureOptions` 传入实时来源，后台编译并安装，成功后提交新会话。失败保留旧缓存。运行期间只读，最近成功启动的条件保存至 `capture/bpf`。捕获计数为驱动交付应用的报文数。

显示过滤中的协议、MAC、IP 与 ICMP 类型取交集。MAC/IP 支持源、目的、任一方向。Ethernet 匹配完整链路首部，IPv4/IPv6 按网络层匹配。

`Packet::icmpType` 保存实际读取到的类型字节。`FilterSpec::icmpType` 支持 8、0、11、3，仅与 ICMP 协议组合使用。类型字节未捕获时不命中类型条件。

协议和类型选择立即生效，地址草稿通过“应用”提交。非法地址保留已生效条件。切换其他协议清除类型条件；移除类型条件保留 ICMP。地址应用保留协议及类型。

## 后台与资源

网卡查询和文件准备在独立线程执行，以请求代号隔离过期结果。文件头校验成功后停止当前采集，并交接已打开的读取器；失败保留原会话。

采集使用数据事件和停止事件，缺少数据事件时回退到可中断等待。`requestStop()` 不阻塞界面，结束后排空队列。文件来源在队列满时等待，实时来源计入应用丢弃。

保存以 64 KiB 缓冲写入 `QSaveFile`，成功后原子提交。后台线程不访问可变会话或界面。快照会延长部分报文的生存期，完成后释放引用。

| 限制 | 数值 |
|---|---|
| 每会话包数 | 10,000 |
| 每会话原始字节 | 64 MiB |
| 每会话估算占用 | 64 MiB |
| 队列估算占用 | 32 MiB |
| 单包字段节点 | 4,096 |

捕获、解析、保留、覆盖、应用丢弃和驱动丢包分别计数。不可获取的驱动统计显示“未知”。校验结果计入摘要占用估算，当前字段树占用单独显示。

## 设置与退出

INI 保存主题、窗口、分栏、列布局、网卡、已生效过滤及成功文件操作目录。`filter/icmpType` 只保存有效类型；缺失或非法值回退全部类型，保留其他有效条件。

关闭窗口时异步停止采集，等待准备、详情、流重组与保存结束。关闭 TCP 窗口或按 Esc 会取消重组并异步等待。保存失败保留主窗口和缓存。启动不自动抓包。

## 测试入口

- CI：Windows 2022 界面与核心回归，Ubuntu 24.04 Clang 18 / ASan / UBSan / clang-analyzer。
- `packet_fuzzer`：摘要一致性、字段范围、节点预算。
- `stream_fuzzer`：双向序号、范围连续性、缺口、来源包号与资源预算；`make_fuzz_corpus <路径> --stream` 生成语料。模糊测试目标支持 Clang / libFuzzer 与 MSVC / AddressSanitizer，仅测试目标插桩。
- CTest：核心及 Qt Test 界面回归。
- `make_samples <路径> --analysis`：生成选项、校验和及分片构造样本。
- `make_samples <路径> --stream`：生成 14 包流重组样本；原始 12 包及 21 包样本保持不变。
- `inspect_pcap`、`compare_wireshark.py`：与 TShark 对照字段及校验状态。
- `ui_benchmark --stream-load`：构造来源、解析、队列、缓存、界面、重复后台重组和后台保存。

源码包保留既有 12 包 IPv4 和 21 包 IPv6 构造样本。新增用例位于测试构造器。程序包包含 EtherScope 安装器，Npcap 1.89 从官网下载。
