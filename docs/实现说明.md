# EtherScope 1.11.0 实现说明

## 数据流

Npcap、PCAP 或 PCAPNG -> RawPacket -> decodeSummary -> 有界队列 -> SessionStore -> 筛选与界面。

解析结果与原始字节放在不可变共享报文中。界面每 100 毫秒批量更新。导出共享点击保存时的报文快照。

| 模块 | 职责 |
|---|---|
| core | 协议解析、过滤、PCAP、会话缓存 |
| capture | Npcap、后台准备、队列、异步停止、导出 |
| ui | 数据包列表、字段树、原始字节、统计、设置 |

## 解析

Ethernet、单层 802.1Q、IPv4、ICMP、ARP、TCP、UDP、IPv6、扩展首部与 ICMPv6 使用统一字节边界检查。字段携带偏移与长度，关联原始字节定位。

IPv4 TCP 首片携带不完整 TCP 首部时显示“不完整首部”。捕获截断或非法数据偏移仍报告解析错误。非首片保留网络层字段，不进行重组。

IPv4 选项支持 EOL、NOP、记录路由和格式 0、1、3 的时间戳。其他选项保留类型、长度和原始范围。所有选项限制在 IHL 内，校验长度与指针；EOL 后显示填充。

`Packet::ipv4Checksum`、`icmpChecksum` 保存状态与可选计算值。IPv4 首部完整即可校验；ICMPv4 仅在完整且未分片时校验。校验范围按 IPv4 声明长度计算，排除 Ethernet 填充。校验不一致单独展示，不计入解析错误、警告或异常数。

完整解析接口 `decodePacket()` 保留。摘要路径省去字段对象与显示字符串，完成相同的长度、选项、异常、字段上限及校验和检查。

选择报文后，详情线程通过 `decodeDetails()` 读取共享原始字节。服务保留一个活动任务、一个待处理请求和一个完成结果；新选择覆盖旧请求。请求代号及报文对象拦截过期结果，字段控件按每批 2 毫秒填充。仅保留当前详情。

## TCP 分析

TCP 会话以双向 IP、端口、VLAN 和接口标识聚合，实时与文件分别维护。新 SYN 序号和关闭后的 SYN 创建新会话。记录双向包数、线上字节、载荷字节、SYN 应答时间、完整握手时间及 SYN/FIN/RST 事件。

握手完成要求依次观察 SYN、反向 SYN ACK 和正向 ACK，并匹配序号与确认号。序号计算按 32 位回绕，包含 SYN 载荷。双向 FIN 均获确认后显示“FIN 已确认”。RST 显示“RST 已见”。时间戳倒退时不显示相应耗时。

协议依据：[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)。分组对照：[Wireshark TCP Analysis](https://www.wireshark.org/docs/wsug_html_chunked/ChAdvTCPAnalysis.html)。

TCP 分析不保存原始报文引用，最多保留 1,024 个会话，每个会话保留最近 16 条事件，达到上限按最近使用顺序淘汰。占用与覆盖单独显示。完整性不足的 TCP 报文跳过会话推断。会话筛选与显示条件取交集；跨会话、重新打开文件和新捕获时清除会话条件，设置不保存临时会话编号。

入口为“更多 > TCP 会话”。“查看报文”应用会话条件，“定位”选择对应缓存报文。PCAP 重开后按文件记录重新分析。

“流数据”取得当前缓存中该连接的不可变快照，包含被显示条件隐藏的报文。后台按两个方向重组，使用 SYN 后数据序号及 32 位回绕计算。重叠范围保留最早观察到的字节，分别记录重复数据、部分重叠、顺序缺口、后到补齐与冲突。冲突关联首个字节不一致的原始包，双击包号可以定位。

缺失范围保留 SEQ 和长度，不填充字节或拼接跨缺口内容。未观察到 SYN 时显示“起点未知”；缓存淘汰显示“缓存范围”。FIN 可确定缺失尾部。数据越过 SYN/FIN 边界时显示“序号边界”。重复数据和先后顺序是捕获观察，不直接等同于网络重传或丢包。

重组使用一个活动任务和一个可覆盖的待处理请求，切换会话时取消旧任务。结果同时校验请求代号、会话编号和会话代数。任务结束立即释放原始报文引用，界面仅保留当前结果。表格按模型读取，十六进制与 ASCII 每页最多 1 KiB。

| 重组限制 | 数值 |
|---|---|
| 快照报文 | 10,000 |
| 单次快照原始字节 | 16 MiB |
| 每方向唯一字节 | 1 MiB |
| 每方向数据片段 | 4,096 |
| 每方向序号跨度 | 64 MiB |
| 分析标记 | 1,024 |

达到限制后保留已有结果并显示“达到上限”，超出标记单独计数。活动与待处理快照各自受限，共享报文与缓存重叠部分不重复计为独立原始数据。重组结果占用单独估算。IP 分片重组与 TCP 超时诊断未实现。

## 过滤

BPF 通过 `LiveCaptureOptions` 传入实时来源，后台编译并安装，成功后提交新会话。失败保留旧缓存。运行期间只读，最近成功启动的条件保存至 `capture/bpf`。捕获计数为驱动交付应用的报文数。

显示过滤中的协议、MAC、IP 与 ICMP 类型取交集。MAC/IP 支持源、目的、任一方向。Ethernet 匹配完整链路首部，IPv4/IPv6 按网络层匹配。

`Packet::icmpType` 保存实际读取到的类型字节。`FilterSpec::icmpType` 支持 8、0、11、3，仅与 ICMP 协议组合使用。类型字节未捕获时不命中类型条件。

协议和类型选择立即生效，地址草稿通过“应用”提交。非法地址保留已生效条件。切换其他协议清除类型条件；移除类型条件保留 ICMP。地址应用保留协议及类型。

## 后台与资源

网卡查询和文件准备在独立线程执行，以请求代号隔离过期结果。文件头校验成功后停止当前采集，并交接已打开的读取器；失败保留原会话。

采集使用数据事件和停止事件，缺少数据事件时回退到可中断等待。`requestStop()` 不阻塞界面，结束后排空队列。文件来源在队列满时等待，实时来源计入应用丢弃。

保存以 64 KiB 缓冲写入 `QSaveFile`，成功后原子提交。后台线程不访问可变会话或界面。快照会延长部分报文的生存期，完成后释放引用。

| 限制 | 数值 |
|---|---|
| 每会话包数 | 10,000 |
| 每会话原始字节 | 64 MiB |
| 每会话估算占用 | 64 MiB |
| 队列估算占用 | 32 MiB |
| 单包字段节点 | 4,096 |

捕获、解析、保留、覆盖、应用丢弃和驱动丢包分别计数。不可获取的驱动统计显示“未知”。校验结果计入摘要占用估算，当前字段树占用单独显示。

## 设置与退出

English、简体中文、繁體中文共用一个程序。入口为“更多 > 语言”，切换立即更新标题、控件、表头、协议字段、错误与 TCP 分析。语言保存在 `ui/language`；首次启动匹配系统语言，其他语言回退 English。`--language en|zh-CN|zh-TW` 可指定启动语言。

翻译表嵌入程序资源。静态控件在创建时绑定原文，动态字段与消息独立刷新。翻译后的文字不参与过滤与解析；地址、网卡名称、路径、BPF、原始字节及会话编号保持原值。切换不重建模型或停止后台任务。语言状态的并发读取使用读写锁。

安装器提供三个语言选项，使用 Inno Setup 的固定版本翻译文件。README.md 为 English，README.zh-CN.md 和 README.zh-TW.md 分别提供简中与繁中说明。

INI 保存主题、窗口、分栏、列布局、网卡、已生效过滤及成功文件操作目录。`filter/icmpType` 只保存有效类型；缺失或非法值回退全部类型，保留其他有效条件。

关闭窗口时异步停止采集，等待准备、详情、流重组、应用分析、录制收尾与保存结束。关闭 TCP 窗口或按 Esc 会取消重组并异步等待。保存失败保留主窗口和缓存。启动不自动抓包。

## PCAPNG

CaptureReader 按内容识别经典 PCAP 与 PCAPNG，CaptureWriter 按明确格式写出。支持多 Section、接口、大小端、EPB、SPB、旧式 Packet Block、时间分辨率和时间偏移。未知块流式跳过，单记录上限 16 MiB。不同 Section 的接口映射为会话内唯一编号。

无时间戳报文显示 `-`，不参与曲线和握手耗时。非 Ethernet 链路保留原始字节，不计解析异常。PCAPNG 输出 SHB、IDB、EPB 或 SPB；无法无损表示时返回错误。经典 PCAP 输出要求单一 Ethernet 接口且时间戳完整。保留必要接口元数据，不导入或导出解密密钥块。

## 应用分析

ApplicationAnalysisService 为连接保留 ConversationAnalysis。新增报文经持续 TCP 序列窗口生成连续字节，每个字节只交付一次；乱序等待缺口填补，重复段不重放，冲突保留先观察字节并标记不完整。接口和 VLAN 继续参与连接隔离。

HTTP/1.x 保留首部、消息体、分块与请求队列；HTTP/2 保留方向独立的 HPACK、SETTINGS 和 CONTINUATION；TLS 保留握手、方向序号、流量密钥阶段和 KeyUpdate。UDP DNS 按数据报解析，TCP DNS 保留未完成消息。decodeHttp1、decodeHttp2、decodeTls 和 analyzeConversation 保留整段入口用于对照。

发布消息复制自身的字节范围，偏移相对于不可变消息缓冲；streamOffset 保留流内位置。缓存剪裁只移除过期消息，不重置解析状态。消息窗口达到 1,024 条、4,096 字段或 2 MiB 时移除最旧输出并标记 Limited，后续消息继续解析。缺口、前缀缺失和异常输入不作为确定结果。

密钥日志变化只重建 Client Random 对应秘密发生变化的连接，使用仍保留的原始报文；无关连接保持状态。会话代数、连接修订及密钥修订随结果交接。ApplicationIndex 按条目所有权替换、剪裁及淘汰，不可变 Packet 不保存应用字段。

DNS 解析 UDP 与 TCP 消息及常用资源记录。HTTP/1.x 支持流水消息、请求响应关联、Content-Length、chunked、无消息体和关闭定界。HTTP/2 使用 nghttp2 HPACK，每方向独立上下文，包含 CONTINUATION、流编号、伪首部、DATA、RST_STREAM 和 GOAWAY。

TLS 使用外部 NSS 密钥日志。支持 TLS 1.2 AES-GCM、ChaCha20-Poly1305，以及 TLS 1.3 0x1301、0x1302、0x1303、KeyUpdate 和恢复连接。OpenSSL libcrypto 负责 KDF 与 AEAD，认证成功后提交明文。0-RTT、TLS 1.2 重新协商和 CBC 不解密。密钥日志只记录最近目录，路径和密钥不写入设置；移除或换会话后拒绝旧结果。

原始、重组、解密数据分别使用来源范围。消息字段关联承载报文；明文偏移只用于明文视图。消息、字段和字节视图分批刷新，字段选择高亮字节并筛选关联包号。

实时与文件各自限制输入引用 4 MiB、增量状态 8 MiB、待处理队列 2 MiB、结果交接 3 MiB、索引 8 MiB、密钥文件 4 MiB。单结果 2 MiB、每方向数据 1 MiB、字段总数 4,096、头部 64 KiB 与 256 项。估算包括字符串、字段、容器和索引；释放后台计算状态不撤销已经发布的字段；未处理数据达到上限时标记 Limited。解析临时缓冲独立受协议范围限制。

## 显示表达式

compileDisplayFilter 编译不可变表达式。支持括号、and/or/not、&&/||/!、比较、contains、in 集合、CIDR 与存在判断。字段覆盖链路、IP、传输、会话、DNS、HTTP、HTTP/2 和 TLS。表达式与现有条件取交集。

多值字段使用任一匹配，已知缺失字段比较为假，待分析及不能确定的字段使用三值逻辑。未知条件取反仍为未知。最多 4,096 字节、512 个语法节点、32 层嵌套；非法草稿不替换已生效条件。索引结果批量更新模型，不逐条重置表格。

## 滚动录制

CaptureEngine 在摘要解析和显示队列之前分支原始帧。RecordingService 使用独立线程与 8,192 包或 32 MiB 队列。默认每文件 128 MiB 或 5 分钟，任务磁盘预算 1 GiB。只有完整报文可以触发轮换，无报文不生成周期空文件。

每任务使用独立目录与清单，只删除清单内已关闭的最旧文件。活动文件使用 .pcapng.part，每秒刷新，成功收尾改名。队列满、磁盘不足、删除或写入失败停止录制，采集继续；已写、排队、未写分别计数。停止和退出异步排空，收尾失败保留窗口。

## 构建与质量

固定 OpenSSL 3.5.9 与 nghttp2 1.70.0，源码 SHA-256 存于 scripts/dependencies.json，静态编译，不增加用户运行库安装步骤。依赖许可证随程序与源码提供。

application_fuzzer 覆盖 DNS、HTTP、HTTP/2、TLS 与表达式，file_fuzzer 覆盖文件边界。CI 每目标运行 120 秒，发布检查每目标 30 分钟。tests/verify_tls_interop.py 使用独立 Python SSL 端点核对 TLS 明文字节。代码格式采用 .clang-format；英文注释限定为边界、生命周期、线程和算法契约。

- `tests/verify_tls_suites.py`：独立 OpenSSL 客户端与 Python SSL 服务端，覆盖全部 14 个 AEAD 套件，支持 TShark 对照。
- `tests/verify_capture_interop.py`：固定接口、时间戳、字节及 PCAPNG 导出往返，支持 TShark 对照。

增量检查包括逐字节输入、跨批分段、HPACK 动态表、TLS 套件、KeyUpdate、消息窗口、序号回绕与持续连接。独立 TLS 端点同时核对整段和逐包路径。组合基准等待分析交接完成，并记录分析拒收、连续字节交付、状态淘汰、索引未完成和状态占用。
