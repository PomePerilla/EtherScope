# EtherScope v2.3.0

2026-10-29，Windows x64。安装后使用现有 Npcap；升级保留程序设置。

## 本次更新

- 报文可见列、字段和应用消息支持文本查找，原始字节支持文本与十六进制查找、跨页定位。Ctrl+F 打开，F3 / Shift+F3 切换结果。
- 主窗口和分析面板支持阅读位置后退／前进，使用 Alt+Left / Alt+Right；查找和定位均校验数据来源。
- 捕获情况、分析进度与资源占用集中到可停靠、可浮动的诊断面板。
- 分析结果持续更新时，保留消息与字段选择、字节页和阅读位置。优化大型消息的后台交付，按现有内存预算保留最近整条消息。
- 精简分析面板的标题、来源和说明入口，统一三语言文案；后台更新保留当前单元格列，Esc 优先关闭查找条。
- 修复应用分析定位的来源校验、实时 TCP 会话排序、未知驱动丢包数的呈现和 PCAPNG 导出进度。

## 验证

- 本地完整 CTest 14 组、原有界面用例 98 项、新工作区用例 17 项、后台分析用例 13 项及 772 条翻译检查通过。
- 三语言、双主题、三种尺寸与 100% / 150% / 200% 缩放检查通过。
- 普通和大消息负载各运行 60 秒、处理 60,000 包，队列丢弃均为 0；心跳 P99 分别为 5 / 4 ms，最大 160 / 163 ms，停止 19 / 20 ms，既有内存及导出完整性门槛通过。
- 全新安装、v2.2.1 升级、设置恢复和卸载通过。物理 Ethernet 短时捕获及本机 HTTP 的筛选、分析、定位、PCAPNG 保存重开通过。

详细结果见[检索与课程验收](检索与课程验收.md)。本次发行平台为 Windows x64；Linux 实时捕获后端和跨屏混合 DPI 验收列入后续工作，课程能力逐项核对见[课程要求核对](课程要求核对.md)。
