## 性能对比

相同的既有合成捕获基准运行 60 秒，目标 1000 包/秒，两次均通过原有门限。

| 指标 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 接收包数 | 60,000 | 60,000 |
| 队列丢弃 | 0 | 0 |
| 界面心跳延迟 p99 | 3ms | 2ms |
| 最大心跳延迟 | 8ms | 8ms |
| 数据馈入期间模型重置 | 0 | 0 |
| 停止完成 | 19ms | 17ms |
| 进程峰值私有内存 | 30.18MiB | 44.40MiB |

这是各一次的工程对照，不能把 1ms 差异解释为稳定提速。新版峰值内存增加约 14.22MiB，仍通过既有 256MiB 门限。详细结果分别为 `baseline.json` 与 `after.json`。
