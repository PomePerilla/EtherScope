# EtherScope v1.10.1

Windows x64

1. 解压 `EtherScope-1.10.1-windows-x64.zip`。
2. 下载并安装 [Npcap 1.89](https://npcap.com/dist/npcap-1.89.exe)。
3. 运行 `EtherScope-Setup-1.10.1-x64.exe`。
4. 打开 EtherScope。

| 项目 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%/Programs/EtherScope` |
| 快捷方式 | 开始菜单、桌面 |
| 卸载 | Windows 设置 → 应用 → EtherScope |

驱动和程序分别安装。升级保留设置，卸载保留设置及保存的抓包文件。

| 操作 | 入口 |
|---|---|
| 语言 | 更多 > 语言，English / 简体中文 / 繁體中文 |
| 捕获过滤 | 更多 > 捕获过滤，应用 |
| 抓包 | 选择网卡，开始，停止 |
| 类型筛选 | 协议选择 ICMP，选择类型 |
| 地址筛选 | 地址筛选，填写条件，应用 |
| TCP 会话 | 更多 > TCP 会话 |
| 会话报文 | 选择会话，查看报文 |
| 会话事件 | 选择事件，定位 |
| TCP 重组 | 选择会话，流数据 |
| 流方向 | A -> B 或 B -> A |
| 流标记 | 流数据 > 标记，双击包号或关联包号 |
| 流刷新 | 重组 |
| 字段定位 | 选择数据包，选择字段 |
| 校验和 | IPv4 或 ICMP 的检验和节点 |
| 文件 | 打开，保存 |

| 应用分析 | 更多 > 应用分析，选择消息和字段 |
| TLS 密钥 | 更多 > TLS 密钥日志，选择密钥文件 |
| 密钥更新 | 更多 > 重新载入密钥日志 |
| 移除密钥 | 更多 > 移除密钥日志 |
| 显示表达式 | 更多 > 显示表达式，Enter 应用 |
| 录制 | 更多 > 录制设置，录制到磁盘，开始 |
| 保存格式 | PCAPNG 或 PCAP |

表达式示例：`tcp.port == 443`、`http.host contains "example"`、`dns.qry.type in {1,28}`、`tls.decrypted`。
