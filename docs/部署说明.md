# EtherScope v1.5.0

Windows x64

1. 解压 `EtherScope-1.5.0-windows-x64.zip`。
2. 下载并安装 [Npcap 1.89](https://npcap.com/dist/npcap-1.89.exe)。
3. 运行 `EtherScope-Setup-1.5.0-x64.exe`。
4. 打开 EtherScope。

| 项目 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%/Programs/EtherScope` |
| 快捷方式 | 开始菜单、桌面 |
| 卸载 | Windows 设置 → 应用 → EtherScope |

驱动和程序分别安装。升级保留设置，卸载保留设置及保存的PCAP文件。

| 操作 | 入口 |
|---|---|
| 抓包 | 选择网卡，开始，停止 |
| 类型筛选 | 协议选择 ICMP，选择类型 |
| 地址筛选 | 地址筛选，填写条件，应用 |
| 字段定位 | 选择数据包，选择字段 |
| 校验和 | IPv4 或 ICMP 的检验和节点 |
| 文件 | 打开，保存 |
