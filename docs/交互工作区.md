# EtherScope 交互工作区与按需学习

2026-10-25。v2.2.1 本地预览沿用黄黑视觉、无边框主窗口与三窗格，精修快捷排查、可停靠分析及按需学习入口。

## 快捷排查

数据包列表支持右键、菜单键和 Shift+F10，提供复制单元格、复制可见列整行，以及按源地址、目的地址、协议和 TCP 会话筛选。整行使用制表符分隔，遵循列的显示顺序和隐藏设置。

“作为唯一筛选”替换所有显示条件；“加入当前筛选”与已生效条件作 AND 合并。操作不修改 BPF。生成的表达式通过现有编译器校验后统一应用，输入框和条件条同步更新。报文仍可见时保留选择。

字段菜单支持复制显示值、字段和值、字段对应的十六进制字节。筛选只为已知稳定字段标识且当前表达式引擎支持的项目启用。应用分析中的字节从当前原始、重组或解密缓冲区提取，按当前数据来源定位。

菜单保存打开时的来源与目标身份。来源改变或目标被覆盖后，旧菜单不得操作另一份数据中的同号报文。

“撤回筛选”恢复完整显示条件，最多 20 步；“最近筛选”去重保留最多 20 条。两者仅存在于当前运行内。切换或重置来源会清空撤回栈；最近条目在不适用的来源或代数下禁用。文本输入框保留自己的 Ctrl+C 行为。

## 分析面板

TCP 和应用分析均支持右侧、底部停靠及浮动，同一区域默认使用标签页。停靠工作区位于全宽标题栏和工具条下。停靠标题区合并来源和窗口操作，标签停靠时由标签显示面板名称；浮动窗口使用系统标题栏。应用消息列表初始占约 35%，字段和字节占约 65%；字节超过一页时显示分页操作。

首次打开时，工作区达到 1280×600 逻辑像素则默认右侧停靠，否则浮动。之后保存用户的浮动偏好、停靠位置、尺寸和浮动几何；临时空间不足时浮动，空间恢复后回到原停靠偏好。“更多 > 外观与语言 > 恢复默认布局”重设分析布局。旧有主题、语言、列宽和分隔条设置继续使用。

来源条显示实时接口或文件以及应用分析包号。分析绑定打开时的来源，不随主窗口切换而悄悄更换。来源不同会禁用定位；“分析当前来源”显式重新绑定。来源重置会清空过期结果。定位失败区分来源不同、已被筛选和已覆盖。

成功定位保留面板并暂停实时跟随。停靠切换不重新创建任务；关闭时取消仍在运行的重组，等待其结束后隐藏面板。主窗口退出仍等待捕获、导出、录制和分析安全收尾。

布局设置独立位于 `ui/analysis/v1/`；不保存分析结果，也不跨启动恢复失效的数据来源。

## 按需学习

字段说明默认折叠，从字段标题右侧打开；内容可选择复制，较长内容可滚动。说明按稳定标识匹配。初期覆盖 Ethernet 地址、EtherType、VLAN ID、IPv4/IPv6 地址和常用首部字段、TCP/UDP 常用字段、ICMP/ICMPv6 Type/Code，以及 DNS 查询名、HTTP Host、TLS SNI。未覆盖字段仍可复制和定位字节。

表达式帮助提供 8 个可编译示例。点击示例只修改草稿，由 Enter 应用。说明区明确区分 BPF 和显示表达式，并说明应用字段可能处于未知状态。

点击分析状态按钮可展开说明，覆盖待分析、完成、未完整、资源受限、缺少密钥、不支持和认证失败。下一步入口分别引导调整筛选、加载密钥或检查字节。说明直接呈现当前状态和可执行操作。

协议含义参考 [TCP RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)、[IPv4 RFC 791](https://www.rfc-editor.org/rfc/rfc791.html)、[IPv6 RFC 8200](https://www.rfc-editor.org/rfc/rfc8200.html) 和 [TLS SNI RFC 6066](https://www.rfc-editor.org/rfc/rfc6066.html)。说明资源随程序提供，运行时无需联网。
