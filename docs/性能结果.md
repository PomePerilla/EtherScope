## 本机 Npcap

Npcap 1.89。回环接口 DLT_NULL，实际 WLAN 接口 DLT_EN10MB。

| 场景 | 交付包数 | 应用丢弃 | 驱动丢包 | 停止 (ms) |
|---|---|---|---|
| 回环 IPv4 回显 | 6 | 0 | 0 | 1 |
| 回环 IPv6 回显 | 6 | 0 | 0 | 2 |
| WLAN DNS BPF | 4 | 0 | 0 | 0 |
| 回环 UDP 20 秒 | 20,000 | 0 | 0 | 2 |
| 回环 TCP 五次握手 | 59 | 0 | 0 | 2 |

回环 UDP 实际发送约 1,000.239 包/秒，共 20,000 包；接收与捕获数量一致。回环 IPv4/IPv6 各核对三次请求和应答；TCP 核对五次完整握手。空闲事件等待和 20 ms 回退等待均检查停止响应。WLAN 为短时 DNS 与安装后抓包，持续实网负载、四类 ICMP 受控实网实验及换机验收未执行。
