## 文件与协议

原有 12 包和 21 包样本分别核对 264、430 个字段值，Wireshark 对照无差异。新增 PCAPNG 固定样本包含两个 Section、三个接口、大小端、二进制时间分辨率、时间偏移、无时间戳和未知块；读取及导出逐字节一致，时间与 Wireshark 一致。

六组独立 Python SSL 端点覆盖 TLS 1.2、TLS 1.3、HTTP/1.x、HTTP/2 和恢复连接。另用 OpenSSL 3.5.7 客户端与 Python SSL 服务端验证全部 14 个支持套件，密文字节封装为测试 PCAP；解密请求与响应逐字节一致，HTTP 字段与 Wireshark 一致。KeyUpdate、错密钥、认证失败、分段、乱序和重传使用定向回归与构造样本。

## 后台与录制

验证异步详情、快速选择、缓存淘汰、会话切换、密钥移除和过期结果。分析队列拒收时仍释放已淘汰报文引用。字段定位按原始、重组与明文来源分开。

录制覆盖大小与时间轮换、空闲无空文件、慢写入、队列满、写入失败、删除失败和收尾失败。失败保留已完成文件与活动文件，既有同名文件不被覆盖；关闭等待与错误保留窗口通过。
