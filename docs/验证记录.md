## 增量协议

覆盖逐字节输入、HTTP 分块与关闭定界、响应先到与 HEAD 请求后到、HTTP/2 CONTINUATION 和 HPACK 动态表、TLS 1.2/1.3 全部 14 个套件、KeyUpdate、缺密钥及分阶段补充密钥。

固定回归检查 TCP 缺口、乱序、重复段、缓存淘汰、序号回绕和持续连接。24,000 轮请求与响应超过单方向 1 MiB，连续交付字节没有重复，剪裁后驻留估算低于 512 KiB。消息窗口达到上限后继续解析，缓存下界推进后恢复完整状态。

TLS 消息与字段使用不可变范围，来源同时限制在关联报文和消息缓冲内。六组 Python SSL 端点和 14 组 OpenSSL 端点同时核对整段与逐包路径；明文逐字节一致，14 个套件的 HTTP 字段与 Wireshark 一致。

## 后台与资源

验证未交付受限标记、后续成功结果、缓存淘汰后的持续解析、原报文引用释放和无关密钥更新。释放计算状态不撤销已发布字段。会话重置与退出取消继续执行既有回归。

实时和文件分别限制输入引用 4 MiB、增量状态 8 MiB、队列 2 MiB、交接 3 MiB、索引 8 MiB、密钥 4 MiB、结果 2 MiB；两会话静态预算合计 62 MiB，低于应用层 64 MiB 上限。临时解析缓冲继续受协议边界限制。

## 质量检查

本机增量应用模糊测试 121 秒、235,230 次，ASan 未报告错误。[持续集成](https://github.com/PomePerilla/EtherScope/actions/runs/39679401500)包含 Windows 回归及 Linux Clang 18、ASan、UBSan、clang-analyzer 和四目标模糊测试。

原有 12 包与 21 包样本保持原值。文件解析器、抓包协议范围和两行工具栏保持现有接口。

## 性能与部署

TLS HTTP/2 两个流量档位及持续 HTTP 长连接各运行 60 秒，开启录制、索引和两次后台保存。三个档位抓包队列、分析队列与录制拒收或丢弃均为 0，保存和录制核对数量、顺序及字节。具体指标见 [性能结果](性能结果.md)。

三语安装检查各执行 5 秒本机抓包。升级、卸载后个人设置保持原值。程序包只包含安装器，Npcap 保留官方下载链接。

两小时稳定性测试暂缓；持续实网负载、四类 ICMP 受控实网实验和换机验收未执行。
