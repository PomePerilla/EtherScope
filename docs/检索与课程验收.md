# EtherScope v2.3.0 检索与课程验收

2026-10-28 完成本地预览、安装包与源码包验收。v2.3.0 版本信息见[发布说明](发布说明-2.3.0.md)。

## 实现

- 报文可见列、字段、应用消息及完整字节缓冲支持查找；字节支持文本与十六进制，跨页定位。
- 主窗口与分析视图保存本次运行内的阅读历史，支持后退／前进。来源重置清空，目标失效提示重新定位。
- 捕获、分析和资源诊断集中到可停靠、可浮动面板。
- 后台分析刷新保留当前单元格列。Esc 优先收起查找条。
- 大型结果在后台缓存内存估算；消息与字段索引合并超出交付预算时优先保留最近整条消息，保留已生成字段。TLS 密钥关联在裁剪前保存，旧密钥结果继续被拒绝。

操作与实现说明见[检索与排查工作区](检索与排查工作区.md)。

## 课程要求与执行范围

[课程要求核对](课程要求核对.md)列出六项设计要求、五项评分依据和演示步骤。Windows 图形界面、实时 Ethernet 捕获、Ethernet/IP 解析、MAC/IP 过滤及四种 ICMP 均有对应实现。四种 ICMP 的本轮界面核对使用构造 Ethernet 数据。

Linux 实时捕获尚缺 libpcap 后端，现有 Linux CI 只构建核心，完整跨平台要求尚未满足。当前环境为单显示器，跨屏混合 DPI 留待多屏现场验收。
